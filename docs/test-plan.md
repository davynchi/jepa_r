# JEPA Test Plan

Generated by `/plan-eng-review` on 2026-07-15.
Branch: `main`
Repository: `facebookresearch/jepa` working copy

## Affected commands

- `uv run jepa train ...` — validate a single model/policy run, artifacts, failures, and resume.
- `uv run jepa sweep ...` — validate paired replicates, 8/16-cell matrices, failure isolation, aggregation, and reporting.
- `uv run pytest` — full CPU verification.
- `uv build` — wheel and source archive verification.

## Critical paths

### Four SG/EMA policies

For each cell, run one backward pass and assert:

- encoder object identity or separation;
- target latent detached or differentiable;
- context, predictor, and target parameter gradients;
- optimizer parameter membership;
- exact post-Adam EMA formula;
- retained Adam moments in the hybrid cell.

### Synthetic data

- Same paired replicate and index reproduce samples in the pinned environment.
- Cross-environment fixtures use numeric tolerances.
- Different splits and replicates do not share samples.
- All eight policy cells inside a replicate receive identical data/order.
- `A` has the requested operator norm within tolerance.
- `C.T @ C` is identity within tolerance.
- QR sign canonicalization is stable and never emits a zero column sign.
- Burn-in is discarded, windows are adjacent, and returned states match endpoints.
- Linear and nonlinear trajectories are finite.

### Training and final evaluation

- MSE matches a hand calculation.
- Epoch MSE is invariant to the final partial batch.
- Representation metrics use concatenated full-split values.
- Gradient and vector norms use the documented weighting.
- With epochs 5, evaluation interval 3, and checkpoint interval 4: evaluation occurs at 3 and 5; checkpoints at 4 and 5; no duplicate final event is written.
- Test dataset access is instrumented and remains zero until training finishes.

### Resume

- Train `N+M` epochs uninterrupted.
- Train `N`, resume in the same directory to `N+M`.
- Compare parameters, optimizer states, metrics, and unique history rows.
- Reject changed config fields other than an increased epoch limit.
- Reject completed runs and inconsistent history/checkpoint state before mutation.
- Preserve immutable run identity while recording initial/current config hashes and the epoch-extension lineage.

### Metrics and probes

- Covariance/effective-rank formulas use analytic matrices.
- Cover zero spectra, near-singular spectra, `N < 2`, and non-finite inputs.
- Ridge tests verify centering, unregularized intercept, Cholesky solution, validation/test isolation, and constant-target behavior.
- Wide history rows map context, target, and prediction values to exact prefixed columns.
- Missing gradients use `null` and the correct reason.

### Sweep and reporting

- One dynamics and replicate produce eight unique run IDs.
- Both dynamics produce sixteen.
- Meaningful config changes alter the hash; YAML order and output-only fields do not.
- Inject one failed cell: seven peer cells continue, failure state is recorded, aggregates exclude failed metrics, counts remain correct, and command exits non-zero.
- `summary.svg` has MSE/context-rank/target-rank panels, all variant labels, and a failed-run marker.

## Edge cases

- Invalid enum/boolean values and unknown config keys.
- Zero/negative dimensions, noise, intervals, or hidden layers.
- Observation dimension below latent-state dimension.
- Window longer than available post-burn-in sequence.
- EMA decay outside `[0,1)` and transition norm outside `(0,1)`.
- Existing output directory without `--overwrite`.
- Non-finite loss or generated values.
- Empty set of completed sweep cells.
- Unsupported CUDA/MPS resume.

## CI matrix

- Unit/integration and build checks on supported Python versions, CPU only.
- One Python 3.11 smoke job with one epoch, 32 samples, small dimensions, both dynamics, all 16 cells, and a five-minute timeout.
- Hygiene check rejects `torchvision`, OpenCV, Decord, timm, submitit, video modules, and Transformer runtime imports.

## Completion rule

No test may assert only that a file exists when its contents define correctness. Artifact tests must parse and validate schema, epoch, identity, and representative values.
